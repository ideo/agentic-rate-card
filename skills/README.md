# Project skills

This folder contains the reusable Codex skill that belongs with the Agentic Rate Card project.

## Included

- `usage/` — reports a thread's token breakdown, tool activity, elapsed span, and API-equivalent cost from local Codex metadata.

The skill is intentionally kept separate from the Next.js app. It can be copied into a Codex skills directory when you want `/usage` available in another workspace.
